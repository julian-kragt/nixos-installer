**Stage 1.3 — User identity.** Runs on the target (installed bootstrap system, pinned host key).

Purpose: give each user on the host a standalone age key of their own, for that host only, and record its recipient for `.sops.yaml`.

Expects: 0.2 (the users exist), 1.2. The users and their homes come from `users` of `nix.Config.HostInfo` (`<config>#installerData.<host>`).

Must do, for each key of `users`, using its `home`:
- Run as that user through `env.Remote.Quiet()`: `runuser -u <user> -- sh -c …`. `runuser -u` keeps root's `HOME`, so pass the path from `home`, not `$HOME`.
- Create `<home>/.config/sops/age`, run `age-keygen -o keys.txt` there only if the file is missing, then print the recipient with `age-keygen -y keys.txt`.
- Require each recipient to start with `age1`, and store it.

Must not: derive the key from an SSH key, read the private key off the target, or copy the operator key to the target.

Writes State: `UserRecipients` (`map[string]string`, user to recipient).

Legacy reference: none. The bash script copied the operator key to the target, which this replaces.

Done when: a test on `machine.Loopback()` with temp homes shows a second run keeps the same key and recipient; on a real target `keys.txt` is mode 600 and owned by the user.
