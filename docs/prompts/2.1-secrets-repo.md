**Stage 2.1 — Secrets repository.** Runs on the provider.

Purpose: make sure the nix-secrets clone the operator passed is one the installer can commit to and push from, before anything is asked or written.

Expects: 1.3; `Inputs.SecretsDir` from `--secrets` (added with this stage, see below).

Introduces: the `--secrets` input. A field `SecretsDir` on `pipeline.Inputs`, a line in `cmd/nixos-installer/flags.go`, and in `inputs.go` an `askSecretsDir` / `checkSecretsDir` pair modelled on `askConfigDir` / `checkConfigDir` (reuse `askUntil`, `expandHome`; the directory must hold a `.sops.yaml`), asked in `resolveInputs` right after the config. A `secretsRepo(env) git.Repo` helper in `internal/stages/stages.go`, like `configRepo`.

Must do: `RequireCommitted` with the paths the installer writes for this host as managed: `.sops.yaml`, `hosts/<host>.yaml`, `host-users/<host>-<user>.yaml` for every key of `users` from `nix.Config.HostInfo`, and every existing `host-users/<host>-*.yaml` (a removed user's file). Then `RequireInSync`. This is the pair 0.1 uses for the config; a re-run after an interrupted 2.3 is therefore not refused for the host's own files.

Writes State: nothing. The repo is an input, not state.

Done when: a clone with an unrelated uncommitted change, one without upstream and one behind its upstream each fail with a message that says what to do; a clone with only the host's own files changed passes.
